@carabennemsi/plasmid

Dependency-free circular plasmid maps — sequence in, standalone SVG out

npm GitHub plasmid.cloudlab.bio

Everything on this page runs in your browser. No sequence is uploaded anywhere — the renderer is a pure function that takes a nucleotide sequence and returns an <svg> string. 

npm i @carabennemsi/plasmid
